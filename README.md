# Loyalty-4-All official Pages entry

Static publication branch. Select gh-pages and /(root) in repository Settings → Pages → Deploy from a branch. `.nojekyll` disables Jekyll processing.

The secure registration service and Community Edition remain at https://loyalty-for-all-community.sammielee.chatgpt.site/ .
